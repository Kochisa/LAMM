# LAMM

**LAMM（Local AI Model Manager）** 是一款面向 Windows 的本地 AI 模型管理器。

LAMM 本身不绑定特定的推理框架或模型，而是负责统一管理本地 AI 模型、推理引擎、模型参数以及模型生命周期。

目前支持使用 **llama.cpp** 作为推理引擎，并支持用户自行选择、替换和升级不同版本的 llama.cpp。

LAMM 的核心理念：

> **管理模型，而不是绑定模型。**

配置完成后，模型不会在管理器启动时自动加载。所有模型默认保持待机状态，只有在收到 API 请求时，LAMM 才会启动对应的推理引擎、加载模型并转发请求。

请求结束并达到设定的空闲时间后，LAMM 会自动卸载模型并释放资源，从而更加灵活地利用 CPU、GPU 以及内存资源。

整个管理器可以完全离线运行。

---

## ✨ 主要特性

### 模型管理

* 管理本地 AI 模型
* 支持多个模型同时加入模型库
* 模型之间相互独立
* 模型参数由用户根据实际需求主动配置

### 推理引擎管理

LAMM 与具体推理引擎解耦。

目前可以使用 **llama.cpp** 作为推理引擎。

用户可以：

* 自行下载推理引擎
* 自行选择不同版本的推理引擎
* 随时替换或升级推理引擎
* 为不同模型使用不同的引擎配置

添加 llama.cpp 时，只需要指定：

```text
llama-server.exe
```

### 🌐 多语言支持

LAMM 支持以下四种界面语言：

* 🇨🇳 简体中文
* 🇺🇸 English
* 🇯🇵 日本語
* 🇫🇷 Français

## ⚙️ LAMM 的工作方式

LAMM 采用**按需加载、空闲卸载**的运行方式。

管理器启动后不会主动加载任何模型。模型只有在实际收到 API 请求时，才会启动对应的推理引擎并加载。

```text
┌─────────────────────────┐
│       LAMM 启动          │
└────────────┬────────────┘
             │
             ▼
┌─────────────────────────┐
│       模型保持待机       │
│                         │
│   不加载模型             │
│   不占用推理资源          │
└────────────┬────────────┘
             │
             │ 收到 API 请求
             ▼
┌─────────────────────────┐
│     启动对应推理引擎      │
└────────────┬────────────┘
             │
             ▼
┌─────────────────────────┐
│        加载模型          │
└────────────┬────────────┘
             │
             ▼
┌─────────────────────────┐
│        处理请求          │
│       流式返回结果        │
└────────────┬────────────┘
             │
             │ 空闲超时
             ▼
┌─────────────────────────┐
│        卸载模型          │
└────────────┬────────────┘
             │
             ▼
┌─────────────────────────┐
│   释放 GPU / CPU / 内存   │
└─────────────────────────┘
```

这种方式可以让多个模型共存于模型库中，而无需让所有模型同时占用 GPU 显存和系统内存。

## 🔧 参数管理

LAMM 不会在模型导入时自动附加一套固定的推理参数。

新模型添加后，默认不会预设参数。用户可以根据实际硬件、模型以及使用场景主动配置参数。

### 自动调参

LAMM 可以读取模型文件中的相关信息，并结合当前硬件资源提供参数建议。

例如根据模型结构、模型大小以及 GPU 可用显存，对以下参数提供建议：

```text
--ctx-size
--n-gpu-layers
```

自动调参属于**可选功能**。

**模型导入不会自动触发调参，也不会自动应用推荐参数。**

只有用户主动使用自动调参功能后，建议参数才会被应用。

## 🔌 API

LAMM 负责管理模型生命周期，并将 API 请求转发给对应的推理引擎。

当客户端请求一个尚未加载的模型时：

```text
Client
   │
   │ API Request
   ▼
┌─────────────────┐
│      LAMM       │
│                 │
│ 检查模型状态     │
│ 启动推理引擎     │
│ 加载模型         │
│ 转发请求         │
└────────┬────────┘
         │
         ▼
┌─────────────────┐
│    推理引擎      │
│                 │
│ 处理模型推理     │
└────────┬────────┘
         │
         ▼
   Stream Response
         │
         ▼
       Client
```

如果模型已经加载，则可以直接处理后续请求。

当模型达到设定的空闲时间后，LAMM 会自动卸载模型并释放相关资源。
